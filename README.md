# FlowGuard

**Every issue deserves an owner. Every resolution needs proof.**

FlowGuard is an Intelligent Service Operations, Issue Resolution and Accountability Platform.
Employees report issues, support agents resolve them, managers monitor SLAs and escalations,
and administrators configure the system.

## Tech Stack

- Frontend: React, React Router, Axios, Recharts
- Backend: Java 21, Spring Boot, Spring Security, Spring Data JPA
- Database: MySQL 8
